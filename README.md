# 🎬 CineVerse - Movie Search Web Application

CineVerse is a responsive movie search web application that allows users to discover and explore movies in real time using the OMDb API. The application features a modern Netflix-inspired interface, trending movie recommendations, advanced filtering, and detailed movie information.

## 🚀 Features

- 🔍 Real-time movie search
- 🎬 Trending movies section
- 🎭 Detailed movie information
  - Title
  - Poster
  - Rating
  - Genre
  - Cast
  - Runtime
  - Plot
- 🎯 Filters
  - Movie Type
  - Release Year
  - Bollywood / Hollywood
- ⚡ Debounced search for optimized API requests
- 🎨 Netflix-inspired UI
- 📱 Fully responsive design
- 🔄 Dynamic background effects
- ❌ Error handling and loading states

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- OMDb REST API

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/SahilSamaiya2/CineVerse.git
```

### 2. Navigate to project folder

```bash
cd CineVerse
```

### 3. Open the project

Simply open `index.html` in your browser.

## 🔑 API Configuration

This project uses the OMDb API.

1. Visit: https://www.omdbapi.com/apikey.aspx
2. Generate your API key.
3. Replace the API key inside `script.js`

```javascript
const API_KEY = "YOUR_API_KEY";
```
